# Cherivelle V1

Functional interactive birthday-wish prototype inspired by the supplied reference video.

## Run
Open `index.html` directly in a browser, or serve the folder with a local static server.

## Before delivery
- Replace `CORRECT` in `script.js` with the real unlock date/code.
- Replace `[NAME]`.
- Replace placeholder memory blocks with real photos.
- Replace video placeholder with the final video.
- Add final music/audio if desired.

The first version intentionally uses vanilla HTML/CSS/JS so the complete flow can be built and tested quickly before visual polish.
